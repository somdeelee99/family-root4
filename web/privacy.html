ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວ

Family Root • ອັບເດດຫຼ້າສຸດ: 29 ຕຸລາ 2026

ກ່ອນ publish: ກະລຸນາປ່ຽນອີເມວຕິດຕໍ່ຂ້າງລຸ່ມນີ້ ໃຫ້ເປັນອີເມວທີ່ໃຊ້ງານໄດ້ຈິງ ແລະ ໃຫ້ກົງກັບທີ່ລະບຸໃນ Play Console.

ນະໂຍບາຍນີ້ອະທິບາຍວ່າ Family Root ເກັບ, ໃຊ້ ແລະ ປົກປ້ອງຂໍ້ມູນຂອງທ່ານ ແນວໃດ. ແອັບນີ້ເປັນເຄື່ອງມືສຳລັບຄອບຄົວ ເພື່ອສ້າງ ແລະ ຈັດການຜັງໄມ້ຄອບຄົວ, ບັນຊີສະມາຊິກ ແລະ ການສື່ສານພາຍໃນຄອບຄົວ.

1. ຂໍ້ມູນທີ່ເກັບ

  • ຂໍ້ມູນບັນຊີ: ຊື່, ອີເມວ, ຮູບໂປຣໄຟລ໌, ຜູ້ໃຫ້ບໍລິການເຂົ້າລະບົບ (Google/Facebook/Apple/ອີເມວ).
  • ຂໍ້ມູນສ່ວນຕົວທີ່ທ່ານປ້ອນ: ເບີໂທ, WhatsApp, ວັນເດືອນປີເກີດ, ເພດ, ຄວາມສໍາພັນໃນຄອບຄົວ.
  • ຂໍ້ຄວາມ ແລະ ຮູບພາບທີ່ສົ່ງໃນການສົນທະນາພາຍໃນຄອບຄົວ.
  • ຂໍ້ມູນເຕັກນິກ: FCM token ສຳລັບແຈ້ງເຕືອນ, ຂໍ້ມູນ crash ແລະ ການໃຊ້ງານແບບລວມ (Firebase Crashlytics/Analytics).

2. ຈຸດປະສົງການໃຊ້ຂໍ້ມູນ

  • ສ້າງ ແລະ ສະແດງຜັງໄມ້ຄອບຄົວ, ບັນຊີສະມາຊິກ ແລະ ຂໍ້ມູນຄອບຄົວ.
  • ຢືນຢັນຕົວຕົນ ແລະ ຄວບຄຸມສິດ Admin/Member.
  • ສົ່ງແຈ້ງເຕືອນເມື່ອມີຂໍ້ຄວາມໃໝ່.
  • ປັບປຸງຄຸນນະພາບ ແລະ ແກ້ໄຂບັນຫາແອັບ.

3. ການເກັບຮັກສາ ແລະ ການແບ່ງປັນ

ຂໍ້ມູນຖືກເກັບໃນ Google Firebase (Authentication, Cloud Firestore, Cloud Storage, Cloud Messaging, Analytics, Crashlytics). ພວກເຮົາບໍ່ຂາຍຂໍ້ມູນຂອງທ່ານ. ຂໍ້ມູນອາດຖືກສົ່ງໃຫ້ Google/Facebook/Apple ເທົ່າທີ່ຈຳເປັນສຳລັບການເຂົ້າລະບົບ.

ຂໍ້ມູນຄອບຄົວ ແລະ ການສົນທະນາຈະເຫັນໄດ້ສະເພາະສະມາຊິກທີ່ຢູ່ໃນຄອບຄົວດຽວກັນ ຕາມກົດຄວາມປອດໄພຂອງ Firestore/Storage.

4. ການລຶບບັນຊີ ແລະ ຂໍ້ມູນ

ທ່ານສາມາດລຶບບັນຊີໄດ້ໃນແອັບ: ໂປຣໄຟລ໌ → ລຶບບັນຊີ. ລະບົບຈະລຶບບັນຊີ Firebase Auth, ຂໍ້ມູນໂປຣໄຟລ໌ ແລະ ຮູບໂປຣໄຟລ໌. ຖ້າຕ້ອງການລຶບຜ່ານເວັບ ໃຫ້ເບິ່ງ ໜ້າລຶບບັນຊີ.

ໝາຍເຫດ: ຂໍ້ຄວາມໃນການສົນທະນາອາດຖືກເກັບໄວ້ເປັນປະຫວັດຂອງຄອບຄົວ ເພື່ອຄວາມສົມບູນຂອງຂໍ້ມູນຄອບຄົວ. ຖ້າຕ້ອງການໃຫ້ລຶບຂໍ້ຄວາມທັງໝົດ ກະລຸນາຕິດຕໍ່ອີເມວຂ້າງລຸ່ມ.

5. ເດັກນ້ອຍ

ແອັບນີ້ບໍ່ໄດ້ອອກແບບສຳລັບເດັກອາຍຸຕ່ຳກວ່າ 13 ປີໂດຍກົງ. ບັນຊີສະມາຊິກຄອບຄົວຖືກສ້າງ ແລະ ຈັດການໂດຍ Admin ຂອງຄອບຄົວ.

6. ຄວາມປອດໄພ

ການສື່ສານກັບ Firebase ໃຊ້ HTTPS. ການເຂົ້າເຖິງຂໍ້ມູນຖືກຄວບຄຸມດ້ວຍ Firestore/Storage Security Rules ແລະ ສິດ Admin/Member.
